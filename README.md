# mixed-models

Curated utilities, simulations, and worked examples for linear and generalised linear mixed-effects models.

These examples are derived from real solutions I developed while answering questions on [Cross Validated](https://stats.stackexchange.com/users/7486/robert-long), where I am the [top contributor (all-time) on the mixed-models tag](https://stats.stackexchange.com/tags/mixed-model/topusers).

The full archive of ad-hoc scripts used in those answers is available in the [Stackexchange](https://github.com/WRobertLong/Stackexchange) repository. This (current) repository contains a smaller, organised, and actively maintained subset intended for reuse and collaboration.

## Scope

Includes:

- Simulation of hierarchical / multilevel data
- Nested and crossed random effects
- Multiple membership models
- Explicit design-matrix construction (X/Z)
- Diagnostics and validation

## Structure

```
r/        R examples
python/   Python equivalents
docs/     short notes
```

Each example is small, self-contained, and reproducible.
